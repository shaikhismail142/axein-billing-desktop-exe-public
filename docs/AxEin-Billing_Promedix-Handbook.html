Getting Started

Access

Open the app URL (for local dev: http://localhost:3000).

  • If the app is license-gated, activate it via the Activation flow.
  • Use the top-right actions to switch theme and review alerts.
Recommended First Setup
  • Settings: fill Business Profile (name, GSTIN, address, phone).
  • Settings: add Company Bank Details (shown on invoices).
  • Settings: set invoice defaults (notes/terms) if needed.
  • Products: create categories and products, then start billing.

Navigation & UI

App Layout
  • Header: primary navigation (Dashboard, Inventory, Invoices, Reports, Accounting, Settings).
  • Sidebar: quick module shortcuts (collapsible on desktop, drawer on mobile).
  • Alerts bell: low-stock, expiry, and vendor debt reminders.
  • Theme toggle: light/dark mode.
Tip: The UI is optimized for keyboard + mouse. Use table actions (Edit/Save/Export) for fast operations.

Quick Billing

Purpose

Create an invoice fast: search products, add quantities, capture payment, and generate an invoice instantly.

Key Features

  • Customer selection (optional): select existing customer or type a new name.
  • Healthcare fields: Patient Name, Doctor Name.
  • Item fields: Category, HSN, Lot/Batch No, Expiry Date (if available).
  • Payment modes: Paid, Partial, Pending.
  • Auto-generated DC No format: DC/<CompanyName>/<YYYYMMDD>/<HHmm>-<Number>.

Workflow

  1. Open Quick Billing.
  2. Select customer (or leave blank for walk-in).
  3. Search products, click a suggestion to add as a line.
  4. Update Qty/Discount if needed, add Lot/Expiry if applicable.
  5. Choose payment mode (Paid/Partial/Pending) and method (cash/upi/card/bank).
  6. Click Save & View Invoice.

Invoices

Invoice List
  • Search by invoice number or customer name.
  • Sort and filter by date range.
  • Export list as CSV.
  • Payment badge tags: Paid, Partial, Pending.
Invoice Details
  • Shows patient/doctor/DC No (if set).
  • Shows item metadata: Category, HSN, Lot, Expiry.
  • Shows Amount Paid and Pending Amount.
  • Print/PDF button generates a shareable PDF.

Products & Categories

Products
  • Core fields: Name, Selling Price, GST slab, Stock Qty, Low Stock Threshold.
  • Healthcare fields: Category, HSN Code, Lot/Batch No, Expiry Date (optional).
  • Import products via CSV (Products Import) where supported.
Best practice: maintain Categories properly so Quick Billing and reporting remain consistent.

Quotations

  • Create quotes for customers before converting to invoices.
  • Supports additional fields like Lot and Expiry (if available) and product tax details.
  • Convert quotation to invoice when ready.

Inventory

Low Stock

Highlights items at or under threshold. Update values and save where supported.

Expiry

Shows near-expiry and expired products/batches (based on configured near-expiry days).

Stock Adjustments
  • Create draft adjustments and post them to apply stock changes.
  • Use reasons such as damage/loss/correction.

Purchases

New Purchase
  • Add vendor bill details and item lines.
  • Optionally add quantities to inventory immediately.
  • Supports importing lines via CSV in the items grid.
  • Payment tracking: paid amount and pending amount.
Purchases drive Vendor Debt in Accounting when they have pending amounts.

Reports

  • KPIs: Revenue, fast/slow movers, low-stock trends.
  • Dead stock list with pagination.
  • Tax/GST computation chart and links to print/export.

GST (Tax) Report

What It Means
  • Output GST: GST collected on invoices (sales).
  • Input GST: GST paid on purchases (eligible ITC).
  • Net GST: Output − Input (Payable if positive, Credit if negative).
Controls
  • Monthly / Quarterly grouping
  • Toggle to include/exclude draft purchases
  • Export to CSV/Excel for CA submission
  • Print view formatted for A4

Accounting (Debts)

Vendor Debt (Purchases)

Shows payables: vendor bills with pending amounts.

  • Outstanding total per vendor
  • Last transaction date
  • Aging buckets (0–30 / 31–60 / 60+)
Customer Debt (Invoices)

Shows receivables: customers with pending invoice balances.

  • Outstanding total per customer
  • Recent unpaid invoices
  • Aging buckets for receivables
Alerts Bell includes vendor debt reminders so billing/admin teams can follow up quickly.

Settings (Admin)

Business Profile
  • Company name, address, GSTIN, phone, state code.
  • Logo (best for invoice): a wide logo around 600×200 PNG/JPG/WebP.

Bank Details

  • Account name, account number, IFSC, bank name, branch, UPI (optional).
  • Printed in invoice footer.

Invoice Defaults

  • Default Notes / Terms appear in Quick Billing (editable per invoice).

Backup & Restore

  • Backup is generated as a ZIP archive from Settings.
  • Restore re-imports data for disaster recovery.
  • Recommended schedule: daily or weekly backups depending on transaction volume.
Restore overwrites data. Always keep a safe copy of the current backup before restoring.

Printing & PDFs

Invoices / Quotations
  • Use Invoice page Print/PDF to generate a shareable PDF.
  • Print layouts are designed for A4 and include healthcare fields.
GST Summary
  • Print view is optimized for CA submission and includes period and grouping.

Windows Installer

The project includes a Windows installer script to simplify deployment on Windows 10/11.

If your environment requires a fully offline installer bundle, treat the PowerShell script as the starting point and add offline package sources.

Troubleshooting

Common Fixes

  • Changes not showing: rebuild the web container using the local override compose file.
  • Blank print: ensure the printed content is within .print-area (handled for major print views).
  • DB migrations: apply the latest migrations when new fields are introduced (payments, batch/expiry, etc.).

Local Rebuild Command

cd /Users/nadiya/AxEin
